# Notizen

Eigene Mitschriften nach Vorlesungstermin oder Marketing-Management-Phase führen.

Jede Notiz sollte mindestens enthalten:

- verwendetes Modell oder Instrument
- Voraussetzungen und Grenzen der Anwendung
- praktisches Unternehmensbeispiel
- mögliche Relevanz für den Praxisbericht
- Quellen und offene Fragen
